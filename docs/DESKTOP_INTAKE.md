# 草堆与单张卡片

桌面日常入口由草堆和一张临时卡片组成。旧的环形导航、附着式透明连接区和网页字体多选对话框已移除；素材库、Agent 和设置保留在主动打开的完整管理窗口中。

## 操作

| 操作 | 结果 |
| --- | --- |
| 从浏览器拖入地址栏网址、页面超链接 | 在后台查找网页声明的可下载字体、封面和图片 |
| 拖入字体、图片、GIF 或音频文件及直链 | 沿用原来的校验、去重和入库事务 |
| 左键点击草堆 | 查看最近三项收纳；再次点击收起 |
| 最近收纳中的条目 | 在原卡片中查看详情；图片显示缩略图，字体显示家族与款式 |
| 已收纳卡片的复制原文件 | 将原文件放入系统文件剪贴板，粘贴到支持文件的应用或文件夹 |
| 拖出已收纳卡片的预览 | 向目标应用提供原文件副本，素材库中的文件保留 |
| 已收纳字体卡片的导出 | 使用系统保存对话框导出字体原文件 |
| 右键点击草堆 | 原生菜单：全部素材、Agent、设置、退出 |
| 字体卡片的上一款、下一款 | 一次查看一个候选，不默认保存 |
| 图片卡片的上一张、下一张 | 一次查看一张图片，不默认保存 |
| 顶部的图片／字体按钮 | 两类候选同时存在时在原卡片内切换，保留各自浏览位置；只有一类时隐藏 |
| 收纳这款 | 仅保存当前原文件，清理其他候选 |
| 收纳这张 | 仅保存当前图片原文件，同时清理未选中的图片和字体 |
| 信息 | 在同一张卡片内查看来源、缺字和内嵌许可 |
| 最近字体的用途选项 | 稍后确认标题、正文、装饰；成功后进入可用交接 |
| 点击原网页或其他应用 | 收起卡片，原点击继续执行 |
| 关闭卡片、Esc | 清理未确认字体和图片；若正在查找则取消查找 |

没有 Haypile 网页地址栏、嵌入浏览器、网址粘贴快捷菜单或独立字体选择窗口。完整管理中的原有剪贴板素材入口保留。网页 JavaScript、登录资源和准确定位某段文字实际使用的字体不在本版范围内。

最近收纳按最后一次完成的收纳批次排序，重复收纳也会排到前面，不修改原文件时间；旧素材没有批次记录时按副本修改时间补齐。复制与拖出保留原始字节和文件格式，包括 GIF 动画、SVG、音频和字体。未收纳的网页候选不提供原文件取用。复制、拖出与导出不会自动确认用途或进入可用交接；目标应用须支持对应文件格式，文字输入框可能只接收文件地址。文件缺失、被修改或目录暂不可读时停止取用，复制失败保留已有剪贴板内容。

## 窗口与状态

- 待机时仅保留 72 点草堆。卡片是独立的非模态原生窗口，宽 280 点，常规高度 240 点，信息展开高度 320 点；短反馈为 100 点，有取消或重试按钮时为 140 点。
- 卡片内以原文件预览和单个绿色收纳按钮为主，翻页、类型切换和关闭为轻量控件。图片预览高 100 点，字体预览区高 84 点，样张按 2 倍像素缓存并按屏幕密度显示；信息在原卡片内展开，长名称提供完整纯文本和无障碍名称，关闭与翻页支持键盘操作。
- 卡片本体为不透明矩形，没有占据草堆与卡片间隙的透明父窗口，也没有原生窗口阴影。屏幕四角会选择可用的一侧放置，不移动草堆。
- 异步查找结果展示时不激活窗口。主动点击草堆后，关闭按钮获得键盘焦点。检查外部点击的定时器只在卡片可见时运行；没有输入捕获层。
- 查找期间，点回网页仅隐藏进度，查找继续；自己的取消、关闭或 Esc 会中断查找，迟到的结果不会重新展示。取消后待线程停止即释放忙碌状态，可重新拖入；多个网页之间取消也会完成清理。卡片进入候选状态后，关闭它即放弃这一轮未确认候选。关闭后的迟到按钮事件不会重新展开信息或打开素材管理。
- 完整管理由明确入口打开，先收起卡片。它是正常的原生窗口，默认 620 × 520 点，可独立移动和关闭，不随草堆移动。
- 用途按钮的原生选中状态与实际保存绑定。保存失败会恢复之前的选中项。来源和许可为纯文本，长内容在信息区内滚动。
- 复制成功短暂显示在主按钮上，保留字体缺字和许可提示。字体导出的系统保存对话框显示期间保持卡片，取消不写文件。
- 下载、入库和字体预览线程由草堆持有。结果信号提前到达时，等待线程实际停止再释放；退出期间不销毁仍运行的线程。入库线程与界面使用同一份存储配置。

原始文件字节、SHA-256、远程地址和下载限制保持原有契约；字体详情见[字体收纳](FONT_INTAKE.md)。

## 网页图片

网页图片按封面、页面图片、站点图标排序，读取 Open Graph／Twitter 图片元数据、`img src/srcset`、常见 `data-src/data-srcset` 及显式图标链接。相对地址按页面首个带 href 的 base 解析。响应式图片优先尝试声明尺寸较大的候选，失败时使用备用地址；不按浏览器当前视口执行媒体查询，不宣称候选就是屏幕实际显示的图片。图片与字体共用一次 HTML 内容读取。

支持现有 PNG、JPEG、WebP、GIF、SVG 格式；ICO／AVIF 未新增支持。每轮最多显示 12 张图片，单张下载上限 12 MiB，单页成功下载的图片总量上限 40 MiB，最多尝试 24 个图片地址，HTML 仍限制为 2 MiB。该类型的候选或字节额度耗尽时停止扫描。文件须通过现有结构、像素、帧数或 SVG 安全检查，再在后台生成缩略图；网址与原始字节分别去重。网页声明或文件实际宽高均不超过 2 像素的图片会跳过，并继续尝试备用地址；直接拖入小图片不受这一筛选影响。GIF 只预览首帧，收纳保留完整动图，沿用原有待确认用途流程。

顶部类型切换不增加窗口或卡片高度。图片模式仍为 280 × 240 点，信息展开为 280 × 320 点；信息显示来源站点、实际尺寸、格式和未核实的许可状态。点击“收纳这张”沿用现有图片入库事务、分类与 HTTP／MCP 契约。网页提供的 alt 只用于候选展示，不保存完整网页地址、查询参数或网页正文。

不执行 JavaScript、不读取登录资源、不扫描 CSS 背景图片，也不采集整页截图、配色或链接卡片。每个资源沿用禁止私网、重定向和代理的边界；关闭、Esc、点回其他应用或退出会清理两类未确认候选。

```sh
QT_QPA_PLATFORM=offscreen .build-venv/bin/python -m unittest tests.test_web_image_intake tests.test_web_font_intake tests.test_attached_hub tests.test_gui_real_project_confirmation_actions
QT_QPA_PLATFORM=offscreen .build-venv/bin/python -m unittest tests.test_desktop_asset_reuse tests.test_bundle_service
QT_QPA_PLATFORM=offscreen .build-venv/bin/python -m unittest discover -s tests
QT_QPA_PLATFORM=offscreen .build-venv/bin/python scripts/render_hub_visuals.py --out /tmp/haypile-management
```

检查覆盖：两类候选不自动入库、原卡片切换、仅收纳当前一款或一张、原字节与来源站点保留、候选和来源临时文件清理、图片备用来源和实际跟踪像素筛除、额度耗尽后停止扫描、安全拒绝、外部点击仍送达原控件、完成的快速点击计数、多网页查找取消后可重试、取消后的晚到结果与按钮事件、用途保存失败回退、辅助功能切换状态、语言切换、四角定位、完整管理入口、存储配置隔离，以及结果先于线程停止到达时的协作退出。

离屏检查不能代替系统拖拽验收。macOS 原生验收需在隔离素材库中核对浏览器拖入、卡片外第一次点击、键盘关闭、原文件样张、复制后跨应用粘贴、预览拖出、字体导出与取消、用途落盘、原始字节与安全退出。Windows 需单独构建并完成相同操作。
