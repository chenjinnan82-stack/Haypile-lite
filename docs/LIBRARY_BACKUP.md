# 素材库备份与恢复

设置页提供「备份素材库」和「从备份恢复」。日常的草堆、C 环和素材卡片操作保持原样；没有新增常驻窗口。

## 操作

- **备份**：选择保存位置，生成一个 `.haypile.zip` 文件。保存位置必须在当前素材库之外。完成前不会替换同名旧备份。
- **恢复**：选择备份，校验后显示素材数量，确认后恢复到当前空素材库。已有素材、组合或自定义主题内容时拒绝覆盖。
- 主题目录中存在额外文件、子目录或符号链接时也拒绝恢复，避免空库判断遗漏用户内容；已知系统目录元数据文件除外。
- 两项操作在后台执行，可以取消。执行时暂停界面中的收纳及修改；隐藏设置后，再点击草堆可返回进度和取消入口。退出应用会请求取消并等待安全结束。
- 恢复成功后直接刷新素材列表与数量，不需要手动复制文件或修改路径。

## 保存范围

保存库内原文件、来源与许可备注、字体/音频用途、主题中的已确认角色、组合和最近收纳顺序。支持现有素材类型；测试覆盖 PNG、GIF、WAV、TTF。

不保存 GUI 偏好、AI 凭据、日志、缓存、待选网页下载及原始数据库。历史导入批次不原样恢复：新数据库重建最近排序，因此旧批次 ID 不延续。备份是未加密的普通 ZIP 文件，应按素材本身的隐私要求保管。

第一版支持标准存储布局、手动备份和空库恢复；不做云同步、定时备份或多库合并。单包限制为 100,000 个数据文件、100 GiB 展开大小，原文件单个最多 500 MiB，单个 JSON 元数据最多 20 MiB。空间预检查保留 256 MiB 余量；这些是防护上限，不代表已对上限规模做过性能验收。

## 数据保护

- 使用现有入库锁、组合锁和新增主题写入锁取得快照；备份前后核对文件清单与状态。普通主题读取无需等待整个备份。
- 备份只记录相对路径、大小和 SHA-256。恢复拒绝路径逃逸、符号链接、重复成员、大小/校验值不符和跨平台名称冲突。
- 先在独立暂存目录验证原文件、元数据、组合引用，并重建本机路径索引，再切换到空库。确认前后重新核对备份身份，防止选中的文件已被替换。
- 切换前留下持久化记录，原空库内容保留用于回退。切换失败回退；进程中断后，下一次存储启动先回退未完成的切换。最后提交阶段只有有限次重命名，此时取消延迟到提交结束。
- 新库提交后才恢复目录可用状态。应用设置与凭据始终留在当前机器。

## 2026-10-14 存储依赖整理

恢复日志、回退、快照锁和持久化重命名集中在 `storage_transactions.py`。入库启动直接调用这层，不再加载备份服务；备份服务仍复用入库服务重建暂存索引，依赖方向保持单向。主题写入使用同一恢复标记常量。

恢复数据库中的路径与最近顺序，以及记录检查、WAL 刷盘由 `StorageRuntimeDB` 负责，备份服务不再直接执行 SQL。备份格式、设置入口和操作步骤不变。桌面窗口之间的依赖、查询时的主题修复尚未调整。
